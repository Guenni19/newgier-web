# newgier-web

Die Website unter https://newgier.app (GitHub Pages). Keine Build-Schritte, reines HTML.

- `index.html` - kurze Startseite
- `datenschutz/index.html` - Datenschutzerklaerung der App. **Quelle ist
  `NutrientTracker/docs/datenschutz.html`**; hier liegt die veroeffentlichte Fassung
  (Datum und Version eingesetzt). Aendert sich die Erklaerung, dort aendern und hierher kopieren.
- `CNAME` - die Domain fuer GitHub Pages
- `.nojekyll` - GitHub soll die Dateien unveraendert ausliefern

Die Seite laedt nichts von fremden Servern (keine Schriften, keine Skripte, keine Zaehler).
